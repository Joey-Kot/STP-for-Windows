# Third-Party Notices

The Windows binary is implemented in Rust. Release packages include complete
third-party license materials in `THIRD_PARTY_LICENSES/`.

## keybd_event compatibility implementation

- Reference version: v1.1.2
- Source: https://github.com/micmonay/keybd_event
- License: MIT
- Full license text: `THIRD_PARTY_LICENSES/keybd_event-MIT.txt`
- Note: the Rust keyboard module directly reproduces the relevant Windows
  `keybd_event` scan-code, virtual-key, flag, and key-order behavior.

## Rust dependencies

The Rust dependency graph is locked by `Cargo.lock`. The release workflow
generates `THIRD_PARTY_LICENSES/RUST-DEPENDENCIES.html` with `cargo-about` and
ships that file with the release archive. It contains crate names,
versions, sources, license identifiers, copyright notices, and full license
texts for the resolved Windows target dependencies.

Primary direct crates:

- `clap` — MIT OR Apache-2.0
- `serde`, `serde_json` — MIT OR Apache-2.0
- `reqwest` — MIT OR Apache-2.0
- `tokio`, `tokio-util` — MIT
- `thiserror` — MIT OR Apache-2.0
- `async-trait` — MIT OR Apache-2.0
- `url` — MIT OR Apache-2.0
